# 🐢 Turtle Movement Controller

This project uses Python’s `turtle` module to create an interactive turtle that responds to keyboard input. You can move, rotate, and reset the turtle using your keyboard.

## 🎮 Controls

- `W` — Move forward  
- `S` — Move backward  
- `A` — Rotate left (counterclockwise)  
- `D` — Rotate right (clockwise)  
- `C` — Clear the screen and reset the turtle to the center

## 🧠 Things to note

- Event-driven programming with `onkey()`  
- Basic movement control using Turtle  
- Screen listening and input handling  

## 🚀 How to Run

python main.py
